# Plan: Restructure to Multi-Module Gradle Project

## Current State
- Single-module Spring Boot 3.5.16 project (Java 21, Gradle 9.7.1)
- Group: `com.ai`, package: `com.ai.web_evaluator`
- Dependencies: Spring WebMVC, Data JPA, Security, Validation, Flyway, PostgreSQL, Actuator, Lombok
- **No business logic yet** — only `WebEvaluatorApplication.java` and test class
- No Dockerfile, docker-compose.yml, CI/CD, or gradle.properties

## Target State
Multi-module Gradle project with 14 modules + root app + admin-ui.

## Decisions
- **Package prefix**: Will change from `com.ai.web_evaluator` to `com.webevaluator` to match the target structure (`com.webevaluator` in `app/src/main/java/com/webevaluator/`)
- **Module naming**: Keep module names as specified (core, api, auth, etc.)
- **Admin UI**: Create as placeholder (static files directory) — user can add actual frontend later

---

## Step-by-Step Implementation

### Step 1: Create root-level configuration files

**1.1 `gradle.properties`** — centralize versions:
```properties
springBootVersion=4.1.1
flywayVersion=11.0.1
postgresqlVersion=42.7.3
lombokVersion=1.18.38
junitJupiterVersion=5.12.2
# ... other shared versions
```

**1.2 `Dockerfile`** — multi-stage build for the `app` module:
- Stage 1: Maven/Gradle build
- Stage 2: Slim JRE image with JAR

**1.3 `docker-compose.yml`** — services:
- `app` — the Spring Boot application
- `postgres` — PostgreSQL database
- `admin-ui` — nginx serving static files from `admin-ui/`

**1.4 `.github/workflows/ci.yml`** — CI pipeline:
- Trigger on push/PR to main
- Steps: checkout, gradle cache, build, test, package

**1.5 Update `.gitignore`** — add module-specific build dirs, admin-ui assets

### Step 2: Restructure `settings.gradle`

Replace with all module names:
```groovy
rootProject.name = 'web-evaluator'
include 'app', 'core', 'api', 'auth', 'orchestrator', 'scenario-bdd',
        'scenario-exploratory', 'scenario-monkey', 'scenario-ai',
        'crawler', 'ui-actions', 'ai-gateway', 'oracle', 'reporting', 'security'
```

### Step 3: Create root `build.gradle`

Root build.gradle with:
- Common Java toolchain (Java 21)
- Spring Boot BOM / dependency management
- Shared dependency declarations (versions from gradle.properties)
- Subproject configuration block

### Step 4: Create module directories and `build.gradle` files

Create each module directory with its `build.gradle`:

```
core/build.gradle       — common utilities, base entities, shared configs
api/build.gradle        — REST controllers, DTOs, uses: core, security
auth/build.gradle       — authentication/authorization, uses: security, core
orchestrator/build.gradle — test orchestration logic, uses: core, scenario-*
scenario-bdd/build.gradle — BDD test execution, uses: core
scenario-exploratory/build.gradle — exploratory testing, uses: core
scenario-monkey/build.gradle — monkey testing, uses: core
scenario-ai/build.gradle — AI-driven testing, uses: core, ai-gateway
crawler/build.gradle    — web crawling, uses: core
ui-actions/build.gradle — UI interaction primitives, uses: core
ai-gateway/build.gradle — AI service gateway, uses: core
oracle/build.gradle     — test oracle / result analysis, uses: core
reporting/build.gradle  — test reporting, uses: core, api
security/build.gradle   — shared security config, uses: core
app/build.gradle        — Spring Boot app, depends on all modules above
```

Each module build.gradle will have:
- `id 'java-library'` (or `id 'org.springframework.boot'` for `app`)
- Dependencies referencing shared versions from root

### Step 5: Move existing code into `app` module

**5.1 Create directory structure:**
```
app/src/main/java/com/webevaluator/
app/src/main/resources/
app/src/main/resources/db/migration/
app/src/test/java/com/webevaluator/
```

**5.2 Move `WebEvaluatorApplication.java`:**
- Change package from `com.ai.web_evaluator` → `com.webevaluator`
- Move to `app/src/main/java/com/webevaluator/WebEvaluatorApplication.java`

**5.3 Move test class:**
- Change package → `com.webevaluator`
- Move to `app/src/test/java/com/webevaluator/WebEvaluatorApplicationTests.java`

**5.4 Move `application.yaml`:**
- Move to `app/src/main/resources/application.yml`
- Expand with database, security, and module-specific configs

**5.5 Create placeholder `app/src/main/resources/db/migration/V1__init.sql`:**
- Empty or basic schema placeholder

### Step 6: Create minimal module source stubs

For each module, create a minimal Java class to satisfy Gradle:

```
core/src/main/java/com/webevaluator/core/CommonUtils.java
api/src/main/java/com/webevaluator/api/ApiModuleConfig.java
auth/src/main/java/com/webevaluator/auth/AuthModuleConfig.java
... etc for each module
```

Each stub will be a simple `@Configuration` class or utility class — can be removed later when real code is added.

### Step 7: Create `admin-ui/` directory

```
admin-ui/
├── index.html          — placeholder
├── css/
├── js/
└── README.md           — instructions for adding frontend
```

### Step 8: Clean up old structure

- Remove `src/main/java/com/ai/web_evaluator/` directory
- Remove `src/main/resources/application.yaml`
- Remove `src/test/java/com/ai/web_evaluator/` directory

### Step 9: Verify the build

Run:
```bash
./gradlew clean build
```

Expected: all modules compile, tests pass, JAR created in `app/build/libs/`.
